Autentikasi & Manajemen Sesi

Alur login, register, logout, dan proteksi halaman menggunakan PHP Session.

File yang Terlibat

session/login.php — Validasi kredensial, set $_SESSION
session/logout.php — session_destroy(), redirect ke index
session/register.php — Validasi input, hash password, INSERT user
includes/auth.php — Guard: cek $_SESSION, redirect jika tidak ada
admin/includes/auth.php — Guard khusus admin (cek role)
admin/login.php — Login terpisah untuk admin
admin/logout.php — Logout admin

Mekanisme Keamanan

  • Password di-hash menggunakan password_hash() PHP sebelum disimpan ke database.
  • Verifikasi menggunakan password_verify() — tidak pernah membandingkan plaintext.
  • Setiap halaman terproteksi meng-include includes/auth.php di baris pertama.
  • Sesi admin dipisah dari sesi user biasa menggunakan variabel sesi berbeda.
  • Logout menghapus seluruh sesi dengan session_destroy() dan redirect ke halaman login.
  • Profile foto disimpan di assets/profiles/ dengan format profile_{id}_{timestamp}.ext.
