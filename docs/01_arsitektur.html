Arsitektur Sistem Greymist

Gambaran menyeluruh arsitektur three-tier, alur data antar layer, dan peta folder proyek.

Three-Tier Architecture

Greymist mengimplementasikan arsitektur tiga lapisan yang memisahkan tanggung jawab dengan jelas:

  • Presentation Layer — Semua yang dilihat pengguna di browser: HTML partials (part/), CSS utilitas (assets/Style/ + GREYMIST_CSS_VAR/), JavaScript vanilla (assets/JS/), Font Awesome, Sortable.js, dan modal dialogs.
  • Application Layer — Logika bisnis di server: halaman PHP utama di root, komponen reusable di includes/, REST endpoints di api/, panel admin di admin/, dan konfigurasi di config/.
  • Data Layer — Penyimpanan data: MySQL untuk data relasional, file system untuk gambar/aset, JSON untuk konfigurasi, dan SQL dumps untuk backup.

Pola Komunikasi

  • AJAX (Frontend → API) — JavaScript di browser mengirim request ke endpoint api/*.php tanpa reload halaman. Ini yang membuat editor terasa real-time.
  • PHP Include — Halaman utama (dashboard.php) memuat komponen modular dari part/ menggunakan include() PHP.
  • Session — Autentikasi dikelola via PHP Session yang dicek oleh includes/auth.php dan admin/includes/auth.php.
