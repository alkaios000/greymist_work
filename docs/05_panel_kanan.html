Panel Kanan – Editor Properti CSS

Panel kanan menampilkan semua properti CSS dari objek yang sedang aktif, dibagi dalam sub-menu tematik.

Peta Sub-Menu Panel Kanan

📦 Box Model

  • Width, Height (px, %, em, vh, vw)
  • Position: static/relative/absolute/fixed/sticky
  • Top, Right, Bottom, Left (offset)
  • Margin (atas/kanan/bawah/kiri)
  • Padding (atas/kanan/bawah/kiri)
  • Box sizing: content-box / border-box
  • Float & Clear
  • File: box.html, offset_var.css

🎨 Background

  • Background color (color picker)
  • Background image (dari aset upload)
  • Background position (x/y)
  • Background repeat (repeat/no-repeat/cover)
  • Live preview warna via bg-color.js
  • Preview code via live-preview.js
  • File: background.html, background_color_var.css

🔤 Typography

  • Font family (pilihan font)
  • Font size (px/em/rem)
  • Font weight (100–900)
  • Font style (normal/italic)
  • Text alignment (left/center/right/justify)
  • Text decoration (underline/line-through)
  • Color teks (color picker)
  • File: typograph-menu.html, font_family_var.css

🖥️ Display & Flex

  • Display: block/flex/grid/inline/none
  • Flex direction, wrap, justify, align
  • Gap antara child elemen
  • Modal advanced flex/grid via display_modal/
  • Shortcut flex via flex-shortcut.js
  • Shortcut box-shadow via box-shadow-shortcut.js
  • File: display-menu.html, flex_properties_var.css

🔦 Filter

  • Blur (px)
  • Brightness (%)
  • Contrast (%)
  • Grayscale (%)
  • Hue-rotate (deg)
  • Invert (%)
  • Opacity (%)
  • Saturate (%)
  • File: filter.html, filter_var.css

🖱️ Hover State

  • Edit properti CSS untuk state :hover
  • Semua properti box model bisa diatur untuk hover
  • Background color hover
  • Border hover
  • Opacity/transform pada hover
  • Pseudo-class didokumentasikan di readme/pseudo-class.txt
  • File: hover.html
