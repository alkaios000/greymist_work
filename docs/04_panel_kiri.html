Panel Kiri – Objek, Aset, Ikon & DOM

Panel kiri menyediakan semua elemen yang bisa ditambahkan ke kanvas beserta browser aset dan pohon DOM.

Struktur Tab Panel Kiri

Alur Tambah Objek ke Kanvas

  • User klik objek di tab Objek → object-menu.js memproses klik.
  • div-define.js membuat elemen HTML baru dengan atribut default.
  • object-handler.js memasang event listener drag, resize, klik.
  • Objek ditambahkan ke frame aktif di kanvas.
  • State disimpan ke undo stack oleh undo-redo.js.
  • Setelah perubahan selesai, api/save_cores.php menyimpan ke DB.

Alur Tambah Ikon Font Awesome

  • Read-icons.py memproses data FA dan menghasilkan assets/JSON/icons.json.
  • User membuka tab Aset → Ikon.
  • render-icon.js memuat dan merender ikon dari JSON.
  • User bisa cari dengan icon-search.js atau filter via icon-category-filter.js.
  • Klik ikon membuka modal detail (icon-detail.html) untuk pilih ukuran/warna.
  • Ikon ditambahkan ke kanvas sebagai elemen <i class="fa-...">.
