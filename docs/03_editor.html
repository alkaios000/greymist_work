Alur kerja editor: manajemen frame, objek di kanvas, undo-redo, zoom, context menu, dan sinkronisasi ke server.

Manajemen Frame

  • Setiap proyek bisa punya banyak frame (halaman/layar).
  • Frame ditampilkan di bar bawah kanvas — bisa diklik untuk berpindah.
  • Tombol + memanggil api/add_frame.php.
  • Klik kanan frame membuka part/modal/frame-menu.html dengan opsi: rename, copy, delete, reorder.
  • Urutan frame bisa diubah via drag using Sortable.js (swap-frame.js).
  • Thumbnail frame diambil via api/get_thumbnail.php.
  • Frame tersembunyi bisa ditoggle oleh hide-show-frame-menu.js.

Objek di Kanvas

  • Objek didefinisikan di object-define.js — setiap objek punya atribut HTML + style CSS.
  • Saat objek diklik, object-active.js menandainya sebagai active dan memuat propertinya ke panel kanan.
  • Perubahan ukuran/posisi dideteksi oleh object-change.js dan disimpan via api/save_cores.php.
  • Kloning objek dilakukan oleh clone-object.js.
  • Hapus objek via tombol Delete keyboard (delete-object.js) atau context menu.
  • Atribut objek (id, class, src) bisa diedit di bar atribut (object-attribute.html).

Zoom & Display

  • Zoom kanvas dikelola oleh assets/JS/user_interface/main/zoom.js.
  • Shortcut keyboard Ctrl+Scroll atau tombol zoom di topbar.
  • Display panel shortcut (block/flex/grid/inline) tersedia via display-panel.js.
  • Modal advanced display di part/modal/display_modal/ (block, flex, grid, inline).
  • Flex shortcut panel via flex-shortcut.js dan shortcut transparan via transparent-shortcut.js.

Context Menu (Klik Kanan)

  • Context menu muncul saat klik kanan pada objek di kanvas.
  • menu-trigger.js — Deteksi klik kanan dan tampilkan menu.
  • menu-actions.js — Eksekusi aksi yang dipilih.
  • copy-paste.js — Copy/paste objek beserta seluruh style-nya.
  • select-parent.js — Pilih elemen induk dari objek yang dipilih.
  • gm-make-as-link.js — Ubah objek menjadi elemen anchor (<a>).
  • Style context menu di assets/Style/main/context-menu.css.
