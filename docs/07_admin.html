Panel Administrasi

Admin memiliki panel terpisah untuk mengelola seluruh pengguna, proyek, laporan, dan pengaturan sistem.

Alur Navigasi Panel Admin

Fitur Manajemen User

  • Lihat semua user terdaftar (nama, email, tanggal daftar).
  • Aktifkan / nonaktifkan akun user.
  • Lihat jumlah proyek per user.
  • Data diambil via AJAX ke admin/get_user.php.
  • Semua halaman admin diproteksi oleh admin/includes/auth.php.

Fitur Manajemen Proyek

  • Lihat semua proyek dari semua user.
  • Preview proyek langsung via admin/preview_project.php.
  • Data diambil via AJAX ke admin/get_project.php.
  • Filter proyek per user.
  • Akses ke frame dan thumbnail proyek.

Template Global

  • Admin bisa membuat template yang tersedia untuk semua user.
  • Template bisa berisi layout siap pakai.
  • Dikelola via admin/templates.php.
  • User mengakses template dari panel kiri editor.

Laporan & Pengaturan

  • reports.php: Statistik penggunaan sistem (jumlah user, proyek, dll).
  • settings.php: Konfigurasi global aplikasi.
  • Sidebar admin disediakan oleh admin/includes/sidebar.php.
  • Backup database disimpan otomatis di folder backups/.
