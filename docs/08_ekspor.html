Fitur Ekspor – Kebaruan Versi 1.0

Fitur unggulan versi ini: ekspor desain elemen/menu dari kanvas menjadi file HTML yang bisa langsung digunakan.

Alur Ekspor Desain ke HTML

File Terlibat

  • part/modal/eksport.html — UI modal ekspor dengan preview kode.
  • part/modal/frame-menu.html — Menu aksi frame (termasuk trigger ekspor).
  • part/modal/object-menu-modal.html — Modal aksi objek.
  • Tombol ekspor di topbar (part/main/frame/top-slide.html).

Output Ekspor

  • HTML dengan struktur elemen lengkap sesuai kanvas.
  • CSS inline atau dalam tag <style>.
  • Class dari GREYMIST_CSS_VAR dikonversi ke nilai aktual.
  • Gambar direferensikan dengan path relatif.
  • Ikon Font Awesome dengan link CDN.
